## 🇬🇧 English

**ExoKey 0.2.1**: a small update to 0.2.

**New**
- **Layout per app:** each app gets back the layout you last used in it.
- **New icon.**

**Fixed**
- With an external keyboard, ExoKey sometimes typed `§` instead of `` ` ``.
- The calculator stops at the end of a sentence and rounds results to 3 digits.
- Fewer wrong layout switches mid-word.

**Install:** unzip and move `ExoKey.app` to Applications, or `brew install --cask exokey`. If macOS says “ExoKey.app” Not Opened: System Settings → Privacy & Security → **Open Anyway**, or `xattr -dr com.apple.quarantine /Applications/ExoKey.app`. Requires macOS 13+ on Apple Silicon. Guide: https://exokey.top/guide/. Feedback: https://exokey.top/feedback/

## Русский

**ExoKey 0.2.1**: небольшое обновление 0.2.

**Новое**
- **Раскладка для каждой программы:** программа получает раскладку, в которой вы работали в ней последний раз.
- **Новая иконка.**

**Исправлено**
- С внешней клавиатурой ExoKey иногда печатал `§` вместо `` ` ``.
- Калькулятор останавливается на конце предложения и округляет результат до 3 знаков.
- Меньше ложных переключений раскладки посреди слова.

**Установка:** распакуйте и перенесите `ExoKey.app` в Программы, или `brew install --cask exokey`. Если macOS пишет «ExoKey.app» Not Opened: Системные настройки → Конфиденциальность и безопасность → **Всё равно открыть**, или `xattr -dr com.apple.quarantine /Applications/ExoKey.app`. Нужны macOS 13+ и Apple Silicon. Руководство: https://exokey.top/guide/ru/. Отзывы: https://exokey.top/feedback/

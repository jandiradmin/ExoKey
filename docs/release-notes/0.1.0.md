# ExoKey 0.1.0 — first preview

Automatic keyboard layout switcher for macOS (English / Russian / Ukrainian) with local AI autocomplete.

## What's inside
- **Layout correction**: `ghbdtn` → `привет` after the 3rd letter, by local dictionaries (~4.8M word forms). Works with any installed en/ru/uk layouts.
- **Hotkeys**: ⌃⌥Z undo correction, ⌃⌥X convert last word, ⌃⌥P pause.
- **Learning**: undone corrections become exceptions, repeated unknown words, names and abbreviations go to the user dictionary.
- **Autocomplete (optional)**: gray inline suggestions from a local model (Qwen3-4B, 2.5 GB, downloaded on demand from Settings). Tab — next word, ⇧Tab — whole suggestion, Esc — hide. Uses the text of the current window as context. Nothing leaves your Mac.
- Per-app layouts, inline calculator (`2+2=` → `4`), dictionary editor, phrases, interface in RU / UK / EN, dark theme.

## Install
1. Download `ExoKey-0.1.0.zip`, unzip, move **ExoKey.app** to **Applications**.
2. The preview build is not notarized by Apple yet. On first launch macOS will block it: open **System Settings → Privacy & Security** and click **Open Anyway**.
3. Allow ExoKey in **Accessibility** and **Input Monitoring**.

Requirements: macOS 13+, Apple Silicon.

## Known limitations
- Preview quality: thresholds are being tuned; please report wrong corrections.
- Suggestions appear only in apps that expose text to Accessibility (most native apps, Chrome/Electron apps after a moment).

ExoTools · Exo Network Tools

Усі мережеві утиліти в одному вікні

Ping, traceroute, MTR, Geo MTR з картою маршруту, DNS, NSLookup, whois, сканер портів і тест швидкості. Без командного рядка, без прав адміністратора на macOS. Безкоштовно і з відкритим кодом.

Що вміє

My IP

Публічна IPv4/IPv6, місто, провайдер і ASN, карта. Пошук будь-якої IP-адреси.

IP Config

Інтерфейси, маски, MAC, MTU, шлюз і DNS-сервери — як ipconfig /all.

Ping

ICMP або TCP, живий графік затримки, втрати, джитер.

Traceroute

Маршрут до хоста через ICMP, UDP або TCP.

MTR

Безперервний traceroute зі статистикою втрат і затримки на кожному вузлі.

Geo MTR

MTR + країна, місто й ASN кожного вузла та маршрут на карті.

NSLookup

Ім'я → усі IPv4/IPv6 і ланцюжок CNAME, або IP → ім'я.

DNS (dig)

Будь-який тип запису, системний, Cloudflare, Google, Quad9 або свій резолвер.

Whois

Домени, IP, ASN — сам іде за посиланнями IANA → реєстр → реєстратор.

Port scan

TCP-сканер у стилі nmap: top-100, 1–1024, усі порти або свій список, банери сервісів.

Speed test

Затримка, джитер, завантаження і віддача.

Історія

Останні запити кожного інструмента, «Копіювати звіт», Esc — стоп.

Скріншоти

Встановлення

  1. macOS: відкрийте .dmg і перетягніть ExoTools у «Програми». Під час першого запуску: правий клік на програмі → «Відкрити».
  2. Windows: запустіть ExoTools_x64-setup.exe. Якщо SmartScreen попередить — «Докладніше» → «Усе одно запустити». ICMP ping і traceroute потребують запуску від імені адміністратора, TCP ping працює і так.
  3. Знайшли помилку чи маєте ідею? Напишіть нам.
